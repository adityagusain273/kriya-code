## Short Description (80 chars max)
Full-featured mobile code editor with syntax highlighting, terminal, and code execution.

## Full Description

Kriya (Kriya Code) is a powerful, native code editor and IDE for Android. Edit, run, and ship code directly from your phone with first-party compilation and Git integration.

**Features:**

• **Syntax Highlighting** — Support for Python, Java, C, C++, JavaScript, TypeScript, HTML, CSS, JSON, and Markdown with customizable color themes.

• **Code Execution** — Run your code locally on your device. Supports Python, Java, C/C++, JavaScript (Node.js), and Bash. Download runtimes from the built-in package manager.

• **Terminal Emulator** — Full interactive terminal with PTY support. Automatically uses Termux runtimes when available for access to hundreds of packages.

• **Multi-Tab Editor** — Work on multiple files simultaneously with a tabbed interface.

• **File Explorer** — Browse and manage your project files with a built-in file explorer.

• **GitHub Integration** — Clone, commit, push, and pull repositories directly from the app. Sign in with GitHub OAuth.

• **Live Server** — Preview HTML/CSS/JS projects with a built-in HTTP server and live reload.

• **Extensions** — Language packs ship inside the app and activate based on the languages you pick, so nothing to install manually. An extension API with stable interfaces is documented for pack authors.

• **Find & Replace** — Search across files with regex support.

• **Pinch to Zoom** — Zoom in and out for comfortable code reading on any screen size.

• **Dark Mode** — Beautiful dark theme designed for long coding sessions.

• **Offline First** — Editing works fully offline. Runtimes download once when you choose to install them, then run completely offline.

**Supported Languages:**
Python, Java, C, C++, JavaScript, TypeScript, HTML, CSS, JSON, Markdown, Bash

**Requirements:**
Android 7.0 (API 24) or higher

**Optional:**
Install Termux from F-Droid for access to additional runtimes (Python, Node.js, GCC, and more) without downloading them separately.
